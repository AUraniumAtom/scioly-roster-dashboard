Calculation Reference

This tab documents every statistic shown in the selection app. Calculations are performed independently for MI and MS, so candidates are compared against the appropriate division.

Raw Score

The original score entered for a candidate in an event. Raw-score scales differ by event, so raw scores are not averaged directly across events.

Event P90

P90 = 90th percentile of raw scores in the event and division

P90 provides a high-performance reference point while reducing the influence of one unusually large top score.

Event Percentile

Percentile = relative position within the event's MI or MS score distribution

Ties receive the midpoint of their tied positions. A higher percentile means the candidate scored above more participants in that event.

Normalized Event Score

For 10+ participants: 70% × min(1.05, Raw ÷ P90) + 30% × Percentile
For fewer than 10: 85% × min(1.05, Raw ÷ P90) + 15% × Percentile

The displayed result is multiplied by 100. The P90 ratio is capped at 1.05, limiting the relative-score component to 105. Small event groups rely more heavily on raw score versus P90 because percentiles are less stable.

Tests

Tests = number of events with a populated numeric score

Blank scores are excluded. A score of zero is included as a valid completed test.

Average

Average = mean of all normalized event scores for the candidate

This measures consistency and breadth across every completed test.

Top 4 / Top 3 / Top 2

Top N = mean of the candidate's N highest normalized event scores

If fewer than N tests exist, the calculation uses all available tests. These measures emphasize the candidate's strongest event portfolio.

Best Event

Best Event = highest normalized event score

The main board displays the three best event scores, ordered from strongest to weakest.

Performance Index

With 3+ tests: Index = 70% × Average + 30% × Top-3 Average
With fewer than 3 tests: Index = Average

The Index balances broad performance with added recognition for the candidate's best three events.

Team Index and Team Top-3

Team Index = average Index of selected candidates
Team Top-3 = average Top-3 value of selected candidates

These are descriptive summaries of the current selection and do not change any individual candidate score.

Strong Event and Coverage

Strong = normalized event score ≥ Strong Event Threshold
Covered = number of selected strong candidates ≥ Coverage Needed

The defaults are 60 for the strong threshold and 6 candidates for required coverage. Both controls are editable.

Best Available for Gaps

Recommendations show unselected candidates who meet the strong-event threshold in one or more events that have not yet reached the selected coverage requirement. Candidates marked Do Not Select are excluded.

Tier

The returning-member tier is displayed for historical context and filtering. Tier does not contribute to Average, Top-N scores, Index, coverage, or event normalization.

Grade and Division

MI contains Grades 5–6. MS contains Grades 7–8. Event P90, percentile, and normalized scores are recalculated within each division, not across all four grades together.
